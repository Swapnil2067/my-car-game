# Swapnil The Rider — Asphalt 9 Arcade Legends Edition

A high-octane arcade racing game built with Pygame featuring dynamic physics, police chases, and a 50-car garage system.

## Features

- **50-Car Garage**: Unlock and drive an extensive collection of vehicles from sports cars to monster trucks
- **Triple Nitro Stages**: Activate powerful boost sequences for explosive acceleration
- **Drift Physics**: Master precision drifting mechanics for high-score combos
- **Air-Time Barrel Rolls**: Perform gravity-defying stunts mid-air
- **Dynamic Police Chases**: Evade relentless police pursuits with tactical gameplay
- **Multiple Environments**: Race through City, Desert, Marine, Forest, Snow, and Canyon settings
- **Day/Night Cycles**: Experience different lighting conditions throughout the day
- **One-Way & Two-Way Roads**: Varied track layouts for diverse racing challenges
- **Save/Load System**: Persist your progress and garage unlocks
- **Epic Soundtrack**: Embedded theme music for immersive gameplay

## Requirements

- Python 3.7+
- Pygame
- Assets folder with vehicle sprites and environment textures

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Swapnil2067/my-car-game.git
   cd my-car-game
   ```

2. Install dependencies:
   ```bash
   pip install pygame
   ```

3. Ensure the `assets/` folder contains all required vehicle PNG files and audio files.

## Running the Game

```bash
python game.py
```

## Controls

- **Arrow Keys**: Drive and steer
- **Space**: Activate Nitro boost
- **F**: Toggle fullscreen
- **ESC**: Exit game

## Game Modes

- **Career Mode**: Progress through races and unlock new cars
- **Garage**: View and manage your 50-car collection
- **Police Chase**: High-intensity pursuit encounters
- **Free Roam**: Explore tracks without restrictions
